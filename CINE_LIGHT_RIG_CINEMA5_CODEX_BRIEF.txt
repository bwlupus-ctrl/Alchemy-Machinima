FEATURE 1 — KEY:FILL RATIO CONTROL  (simple, model + UI)
=============================================================================
A single "lighting ratio" control that auto-derives the FILL light's EV from the KEY light's EV.
- New per-rig setting CineLightRigRatioLock (bool) + CineLightRigRatio (F32 stops, or an enum of
  1:1/2:1/4:1/8:1/16:1 mapped to 0/1/2/3/4 stops — you choose; a continuous stops slider 0..5 is
  fine and more flexible). Ratio R:1 => fill_EV = key_EV - log2(R) = key_EV - stops.
- When RatioLock is ON: the model derives FILL mEV = KEY mEV - stops each evaluation (the Fill EV
  control is display-only/driven; grey it or show the derived value). When OFF: today's independent
  Fill EV (byte-identical). Implement the derivation in the pure model (computeLive/base assembly) so
  it is TUT-testable; the UI just exposes the lock + stops.
- TUT: ratio-lock ON with key EV = e and stops = s yields fill EV == e - s (independent literals);
  ratio-lock OFF leaves fill EV untouched (byte-identical to the input).
- UI: a ratio combo/slider + lock toggle near the Fill controls; reset button. Per instance (blob).

FEATURE 2 — CATCHLIGHT / EYE LIGHT  (new optional emitter, moderate)
=============================================================================
A tiny dedicated light that puts a specular catchlight ("sparkle") in the subject's eyes.
- DESIGN DECISION (fixed): do NOT change LIGHT_COUNT or add a 5th logical light (that ripples the
  arrays/presets/exposure). Implement the catchlight as a SEPARATE optional emitter the rig creates
  when enabled — parallel to the existing projector/omni emitters, its own LLPointer, its own
  lifecycle (create on enable, destroy on disable/power-off/shutdown, per instance).
- Placement: a small, bright, small-radius emitter positioned at the subject's EYE joint (reuse the
  lens-gaze eye handling / ANIM_AGENT_EYE eye position; if unavailable, fall back to head joint +
  forward offset), through the finalized foot-pivot scaledPoint()/getUniformScale() so it scales with
  clones. Aim it along the eye->camera axis so the catchlight reflects toward the camera (a catchlight
  is a reflection; position it slightly off the camera-subject axis, near the key side by default).
- Config (per rig, in blob): CineLightRigCatchlight (bool on/off), CineLightRigCatchlightEV (intensity),
  CineLightRigCatchlightSize (radius, small), CineLightRigCatchlightColor or reuse master-temp, and an
  offset/angle so the operator can place the sparkle (classic upper-key-side "11 o'clock"). Keep it OUT
  of the shadow/shaft system (it's a specular accent; it must NOT consume a shadow slot).
- SA/exposure: the catchlight is a fixed small accent; it does NOT participate in the KEY/FILL/RIM/BG
  EV chain or the ratio. Its intensity is its own control.
- TUT where pure-testable (placement scale composition); the emitter lifecycle is review-verified.

FEATURE 3 — THEATRICAL GEL LIBRARY  (per-light colour modifier, moderate)
=============================================================================
Named theatrical gels (Rosco/Lee style) applied PER LIGHT, layered on top of the existing profile
colour and master colour-temp.
- A curated gel table (name -> transform). Two kinds: (a) colour-TEMPERATURE gels — CTO, 1/2 CTO,
  1/4 CTO (warm), CTB, 1/2 CTB, 1/4 CTB (cool) — expressed as MIRED shifts and run through the SAME
  Planckian-locus gain the master colour-temp already uses (reuse that code path, do not fork it);
  (b) COLOUR-CORRECTION / party gels — Plus Green, Minus Green (magenta), plus a handful of saturated
  looks (e.g. Bastard Amber, Steel Blue, Congo Blue, Primary Red/Green/Blue) — expressed as linear
  sRGB multipliers.
- New per-LIGHT setting CineLightRig{Key,Fill,Rim,Bg}Gel (S32 index into the gel table, 0 = none =
  byte-identical to today). The gel transform composes AFTER the profile colour and the master-temp
  gain, before the light is emitted. Gel 0 must be a bitwise no-op.
- Put the gel table + the apply function in the pure model so it is TUT-testable; reuse the master-temp
  mired->Planckian->gain for the CT gels (green-normalized like the master temp).
- TUT: gel 0 == no-op (bitwise); a CT gel equals the equivalent master-temp mired shift applied to a
  known colour (independent expected value); a party-gel multiplier applied to white equals the table
  value.
- UI: a per-light Gel dropdown (grouped: "Colour Temp" gels / "Colour" gels), reset button. Per
  instance (all four ...Gel keys in the blob).
