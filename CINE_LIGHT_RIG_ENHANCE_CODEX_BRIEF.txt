THE TRAPS — get these right (from §7 risks)
=============================================================================
1. FIELD THREADING (R4 — top hazard). LightBase::mGobo MUST be copied in `copyCleanLights` AND
   `computeLive` (the two field-by-field copiers) or gobos silently never render despite compiling.
   test<14>.3/.4 are the tripwires — make them fail if mGobo is dropped in either copier.
2. BACK-COMPAT FAST PATHS. mMasterTempMired default 0 = NO colour change, a BITWISE no-op (like the
   scale s==1 path) — every existing colour test must pass UNTOUCHED. mGobo default 0 = today's
   default cookie. An absent gobo/temp field in an old preset/scene = these defaults. NO version bump;
   a `version` edit anywhere in your diff is a DEFECT (design §9).
3. COLOUR MATH (R3). Master temp is a MIRED trim -> Planckian-locus -> XYZ -> linear-sRGB green-
   normalized GAIN applied to each light's LINEAR rgb, per §A.2. It must PRESERVE relative gel order
   (a cool light stays cooler than a warm one after the shift) and compose correctly with the existing
   setLightSRGBColor linearization and the [0,1] clamp — NOT interact with intensity/headroom (colour
   and intensity are separate channels, proven §1.1). Pin the design's computed gain LITERALS in the
   TUT (e.g. +100 mired -> R x1.4663, B x0.5349 — take the exact table from §A.2). The model does NOT
   gamma-correct; do not add gamma to it.
4. GOBOS ARE PROJECTOR-ONLY. Omni emitters keep null texture. Patterned gobos ride STANDARD beams in
   the presets (Snoot compresses the pattern, Softbox stretches it) — the §D table already encodes
   this; transcribe it exactly.
5. POSITIONAL TABLES (CLAUDE.md rule 6). The 5 gobo presets (§D) and the 7 gobo file names/indices:
   after writing, VERIFY BY COUNTING and cross-check every value against the §D table and §C.1 table.
   All profile idx in [0,23], beam in [0,2], gobo in [0,7], pitch within ±85. A slip ships a scrambled
   preset that compiles fine.
6. GOBO FALLBACK (§C.4). Out-of-range gobo index -> clamp -> default cookie; missing PNG -> default
   cookie + one LL_WARNS; never a black projection. rigGoboTexture holds an LLPointer so the decode
   stays resident.
7. SHADOW FIX-IT (§E). The button and the yellow hint MUST share ONE computeRequestedShadowSlots()
   helper (agreement by construction). The button setU32("BDMergeMaxSpotShadows", clamp[2,6]).
   No pipeline edit — settings write only.
8. PANEL REFLOW. Height 1130 -> 1286; 34 reset buttons total; no overlaps (verify by rect arithmetic);
   both hosts (Director tab + standalone floater) stay coherent.
