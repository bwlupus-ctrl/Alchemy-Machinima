# Wiring audit: camera embedded panels (static)

Date: 2026-10-12. Static read of source only: no build, no run, no commit, no fetch.

## Scope
Seven panels, 820 widgets: panel_cinecam_frame, panel_flycam_orbit, panel_cinecam_operator (embedded with class panel_cinecam_params), panel_cinecam_params, panel_director_switcher, panel_flycam_recorder, panel_temporal_capture.
Hosts: floater_director.xml (switcher 1086, params 1116, operator 1234, frame 1270, orbit 1300, recorder 1322, temporal 1737); kit pages panel_dpage_camera_*.xml; floater_cinematic_camera.xml; floater_flycam_orbit.xml; floater_flycam_recorder.xml; floater_temporal_capture.xml.

## Method
1. Every widget parsed from its XML. control_name widgets checked against the four settings files: existence, Type fit, default inside min/max, increment vs decimal_digits, combo/radio default among items.
2. Reset buttons: each Machinima.ResetControl parameter checked to be a control in the same XML. Callbacks located in C++ (alpanelcinecamparams.cpp:84-117).
3. Widgets without control_name located by quoted-name grep in indra/newview *.cpp/*.h and the owner postBuild read (file:line in the Binding column).
4. Every XUI-bound setting grepped in C++; the 28 settings with a single reference were read at each site.
5. enabled_control gates checked for a visible toggle in the same panel.
Totals: OK=754, TYPE-MISMATCH=1, UNBOUND=2, UNSURE=63 (all 820 widgets) 

## Notes
N1. Frame panel reset buttons (21) and auto_frame_resolve (22 UNSURE rows in total) are UNSURE. Machinima.ResetControl and Machinima.AutoFrameResolve are only registered by alRegisterMachinimaResetControl(), which runs in the constructors of ALPanelCineCamParams, ALPanelFlycamOrbit and ALPanelDirectorSwitcher. ALCineCamFramePanel (llcinematiccamera.cpp:116-117) does not call it. Works in floater_director (switcher precedes frame in XML). Not verified for panel_dpage_camera_frame_orbit.xml, where frame precedes orbit.
N2. TemporalDriveCamera (drive_camera_check, "Camera (stays real-time...)") is INERT. It sets LLTemporalFeature::CAMERA in llpresentationtime.cpp:60 and nothing tests that bit. The Comment in settings.xml also says Inert.
N3. TemporalOutputFPS (output_fps_spinner, "Out FPS") is INERT. The only reference is the scene-save list llfloaterdirector.cpp:1992. No reader.
N4. DirectorSwitcherSequence is a Boolean on a radio group by design (panel_director_switcher.xml:381). Reported as TYPE-MISMATCH for the rule, verdict benign.
N5. Widgets with no label attribute (combo captions, some spinners) are UNSURE: captions come from sibling text not checked here.
N6. Gates: CinematicFrameLensEnabled, CinematicAutoFrameEnabled, CinematicFrameGuideEnabled. Each is toggled by a checkbox in panel_cinecam_frame, so gated widgets are reachable.
N7. Shared settings across panels, all consistent: CinematicCamFrameOffsetUp (frame + operator), TemporalWorldScale (scale_slider + scale_spinner).
N8. The five switcher custom-angle reset buttons (reset_switcher_custom_*) carry no XML callback; they are bound in code at alpaneldirectorswitcher.cpp:159-173.

## Verdict legend
OK = bound and consistent. UNBOUND = no binding or no effect. UNREACHABLE = no user path. MISSING-SETTING = name absent from settings. TYPE-MISMATCH = Type does not fit (see notes). RANGE = default outside min/max, precision finer than decimal_digits, or default not among items. LABEL-MISMATCH = label contradicts its setting. UNSURE = needs runtime check.
