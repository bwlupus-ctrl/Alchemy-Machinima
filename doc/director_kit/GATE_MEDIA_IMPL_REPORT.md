## Decisions, deviations and acceptance limits

- Slice 1 is accepted from the user’s measured clip: 38–43 ms gap against a 44.5 ms frame, zero excess. Native input-repeat remains the loop mechanism. Ladder step (b) was deliberately omitted as instructed; no alternative loop pool or third decoder was introduced.
- `VCamGateMediaCycleEnabled` defaults TRUE under this implementation request, superseding the spec’s original default-false staging instruction. The independent media-slot and Prism switches remain effective.
- The clock is an approximate, instrumented estimator, not frame PTS. Paused seek/new-image and resume/new-image gates are enforced, including stale-clock rejection. The actual estimator bound with delayed callbacks/B-frames, cut-to-motion latency and A/V offset still require recorded in-world measurement. Passing the fake-clock and reducer tests does not certify that hardware bound.
- No 1080p60 hardware qualification, driver/recorder/audio-route baseline, 30-transition capture, shader runtime compile, or in-world native-UI exercise was performed because no viewer build was authorized. The spec’s p95/p99, FPS-loss, repeated-frame, black-frame, flash/clap and duration-less recovery-hitch requirements remain unchanged and unclaimed. The functional manifest labels native fixture work accordingly.
- The prebuild guard itself is unchanged. Its invocation redirects the documented `zs_check -CachePath` into the workspace and supplies a writable XDG Git-ignore location, preserving inherited Git configuration and disabling only safe-CRLF warning output. This avoids sandbox-only path/warning failures; no gate or finding is suppressed. The installed `zs_check` does not map the nested LibVLC project, so a workspace copy adds only that project-path mapping and runs the same `/Zs` logic with the real generated Release flags; LibVLC passed rather than being counted as a skipped TU.
- Generated XUI files outside VCam have generator fingerprint updates; their authored controls were not changed. The row-count increase is exactly 17 and is pinned with its reason. The mockup copies are identical.

No performance threshold, decoder cap, admission policy, or test oracle was relaxed.
