# Wiring audit: Look kit pages (Image, Roto Ink, Tron, Actor FX)

Static audit of the four Look pages converted to generated kit pages on 10/13 (no build, no viewer run). Generated from `indra/newview/skins/default/xui/en/panel_dpage_look_{image,stylize,tron,actor_style}.xml` and checked against the mockup source `scripts/code_tools/director_kit/director_mockup_data.json`, `settings*.xml`, the Lightbox editor `floater_lightbox_settings.xml` (the reference that writes the same settings), the settings comments and the C++ consumers.

## Result

- Generated rows after regeneration: 303 (image 74, stylize 81, tron 130, actor_style 18). Setting-bound 267, code-bound 36.
- Preset strips: 2 (`roto_ink` 63 looks, `tron_look` 15 looks), each a kit preset provider.
- Mockup rows not generated: 3 (see Omitted rows). They are the Rig Rim tint rows represented by Tron's Light > Rim link.
- FAIL: 0 after the fixes listed below. Any mockup row that cannot be verified is listed under Open items, not PASS.
- Ranges with no bounds in the settings comment (10 rows) are PASS by meaning, with the rationale in each row. Confirm them with the user; they are the only soft verdicts.

## Open items (unresolved, reported to the user)

1. **Three mockup rows are not generated** (table below). They are duplicates of settings homed on Rig Rim and are represented by Tron's Light > Rim link.
2. **xui_layout_check --selftest FAILS** (`real legacy pages`): the check pins 30 legacy pages and the gate_policy `xui_legacy_v1_findings` baseline; this batch makes 27 legacy pages. The gate script and baseline are not edited here. Needs an explicit gate update from the user.
3. **Concurrent edits**: `indra/newview/llfloaterdirector.h` and `.cpp` were changed by another process during this batch (scene files, status strip, transport tooltips; not this batch). This batch's edits are interleaved with them. The compile gate passes on the current file (13/13 TUs). Those edits need review before build.
4. **Lightbox-only behaviour not carried over** (display, not wiring): Lightbox hides rows that do not apply to the current mode (for example Roto Ink motion angle, pattern drift). The kit shows all rows (the mockup has no `show_if`). The Lightbox preset combos reset to Preset... after apply; the kit strip shows the applied name.
