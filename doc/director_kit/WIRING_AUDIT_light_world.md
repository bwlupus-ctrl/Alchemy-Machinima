# Light World wiring audit (static)

Date: 2026-10-12. Read-only audit of source. No build, run, commit, or git fetch was done. The only file written is this one.

## Scope and method

- Nine pages in `I:/alchemy-machinima/indra/newview/skins/default/xui/en/` (list below).
- Seven of the nine pages (actors, cues, exposure, practicals, atmosphere, shadows_probes, weather) contain **no `kit_row`**. Their controls are opener buttons plus shared embedded panels (`panel_exposure_hub.xml`, `panel_avatar_light_response.xml`, `panel_atmospheric_volumes.xml`, `panel_projector_shafts.xml`, `panel_weather_settings.xml`). Those panels were audited too and are listed in the table.
- Rig and rim pages: 229 `kit_row` rows (rig 186, rim 43), each with its child widget. Card-level enable, master, and selector switches are listed separately.
- Setting checks: existence and type in `settings.xml`, `settings_alchemy.xml`, `settings_per_account.xml`, `settings_per_account_alchemy.xml` (3,584 names). Range checks use the shipped default against the widget min/max. Per-account overrides were not considered.
- Code checks: C++ handlers traced in `alpanelcinelightrig.cpp`, `alrigrimcontroller.cpp`, `alpanelexposurehub.cpp`, `alpanelatmosphericvolumes.cpp`, `alpanelavatarlightresponse.cpp`, `alpanelweathersettings.cpp`, `alpanelprojectorshafts.cpp`, `llfloaterdirector.cpp`, plus the kit runtime (`alkitcard.cpp`, `alkitpage.cpp`, `alkitrow.cpp`, `alkitpresets.cpp`).
- v1 comparison: every v2 setting checked against v1 XML controls that bind the same `control_name` (`panel_cine_light_rig.xml`, `floater_lightbox_settings.xml`, `panel_projector_shafts.xml`, `panel_exposure_hub.xml`).

Verdicts: OK / UNBOUND / MISSING-SETTING / TYPE-MISMATCH / RANGE / LABEL-MISMATCH / V1-MISMATCH / UNSURE.

Pages: panel_dpage_light_actors.xml, panel_dpage_light_cine_light_rig.xml, panel_dpage_light_cues.xml, panel_dpage_light_exposure.xml, panel_dpage_light_practicals.xml, panel_dpage_light_rim.xml, panel_dpage_world_atmosphere.xml, panel_dpage_world_shadows_probes.xml, panel_dpage_world_weather.xml

## Checks with zero findings

- MISSING-SETTING: 0. Every setting named by a row, a handler, or an embedded control exists.
- RANGE: 0. Every shipped default falls inside its widget min/max (night-mask darkness is shown as percent, so 0.15 floor = 85 %).
- V1-MISMATCH: 0. All 152 v2 settings that have a v1 control bind the same setting.
- All 214 settings-style string literals in the cine panel and rim controller resolve in the settings files; the single exception is the `CineLightRig` name prefix.
- Setter types match settings types for all 127 names written by the cine panel and rim controller.
