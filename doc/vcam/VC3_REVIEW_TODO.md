# VC3 review (Opus, 8083cefbde5: NO-GO). The world shader is verified exact. Fix in the round after VC4.

- BLOCKER, llprismlens.cpp ~2708/~3266 with ~8630-8636: preview-only frames render at the letterboxed size (e.g. 108x108, 192x96) inside the fixed 192x108 pinned pack. bindTarget resets the viewport to the full pack, and the deferred fullscreen passes (postDeferredNoTCV, softenLightF) sample [0,1] over the whole pack, so non-16:9 previews are stretched/cropped/wrongly lit. This breaks "physical size == render size" (pipeline.cpp:1734) and spec 4.5 ("never requests an aspect-specific size"). FIX: ALWAYS render 192x108; handle the aspect purely in the UV mapping (letterbox/pillarbox at atlas-composite time).
- MAJOR, llprismpreview.cpp ~292-293: ScopedPreviewAtlasGL restores the active texture unit / unit-0 binding with raw glActiveTexture/glBindTexture, bypassing the LLRender caches (gGL.mCurrTextureUnitIndex, LLTexUnit::mCurrTexture). Main-view textures can then bind to the wrong unit. The constructor's raw glActiveTexture(GL_TEXTURE0) has the same skew. FIX: use gGL.getTexUnit(n)->activate()/bind/unbind only.
- MAJOR, llprismpreview.cpp ~524-528: onRenderTargetsReleased zeroes mPublicationSerial but not mAtlasSerial, and lens serials restart at 0 (llprismlens.cpp ~2428/~2466), so hasPendingAtlasUpdate stays false and tiles freeze for minutes after any GL-target release; tile state stays LIVE with a stale generation. FIX: reset/rebase all serials together and mark the tiles stale.
- MINOR: setDemand doesn't clear mSelection[slot] when a slot is reused by a new generation (a new capture shows OFFLINE instead of raw). Clear it on generation change.
- MINOR: face tiles (~9487) stretch the face aspect into the 16:9 cell, while raw is centered. Center/letterbox the face output too.
- MINOR: PAUSED/THROTTLED are only computed when a publication arrives, so a paused capture never shows PAUSED. Compute the state every tile query from the current flags.
- MINOR: spec 4.1 contract: add the EMPTY/HELD/ERROR states, connectChanged (a signal for the UI) and a distinct "shader unavailable" state.
