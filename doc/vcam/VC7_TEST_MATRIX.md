# VC7 manager convergence test matrix

## Scope and automation key

Run every mutation once in the full Prism manager and once in Director v2 > Camera > VCam, starting from the same saved scene. The resulting capture/display settings and the rejection text must match exactly. VCam intentionally has no undo or redo, so neither appears in this matrix.

The Director functional self-test exercises UI wiring, not rendered output or registry semantics. Relevant manifest rows are:

- `v2:vcam_tab:prism_lens_enabled:732` (master), `v2:vcam_tab:vc_previews:vcam`, `v2:vcam_tab:vc_monitor_size:vcam`, `v2:vcam_tab:vc_monitor_pager:vcam`, and `v2:vcam_tab:vc_monitor_strip:vcam`.
- `v2:vcam_tab:vc_add_camera:vcam`, `v2:vcam_tab:vc_remove_capture:vcam`, `v2:vcam_tab:vc_add_face:vcam`, `v2:vcam_tab:vc_add_screen:vcam`, and `v2:vcam_tab:vc_remove_face:vcam`.
- `v2:vcam_tab:vc_face_feed:vcam`, `v2:vcam_tab:vc_face_fit:vcam`, `v2:vcam_tab:vc_rate_mode:vcam`, and `v2:vcam_tab:vc_rate_preset:vcam`.
- `v2:vcam_tab:vc_bone_anchor:vcam`, `v2:vcam_tab:vc_bone_joint:vcam`, `v2:vcam_tab:vc_bone_aim:vcam`, and `v2:vcam_tab:vc_bone_roll:vcam`.

The C++ automated suites cited below are `llprismpreviewpolicy_test`, `llprismgate_test`, and `alvcambonepov_test`. “In-world” means the functional row is at most partial coverage and the stated visual/runtime result still requires a logged-in viewer.

## Page-model API gaps encountered (not fixed in VC7)

- No `removeDisplay()` adapter exists. Both current UIs therefore still call `LLPrismLens::removeDisplay()` directly; convergence cannot route this mutation through `ALVCamPageModel` without changing the read-only model.
- No display Gate-subscription adapter exists. Both current UIs still call `LLPrismLens::setDisplayGateSubscribed()` directly.
- `bindSelectedFace()` and `addVirtualScreen()` do not return or select the created display handle. The manager preserves its prior select-after-add behavior by diffing the bounded pre/post display sets.
- There is no page-model adapter for rebinding a camera to the selected object (`setSelectedCamera`), Gate settings/arm/disarm/TAKE, or a status/preflight API for virtual-screen creation.
