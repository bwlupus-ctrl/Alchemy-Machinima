# Client perf plan — 2026-10-07

These are merged findings from:
- four Codex investigations (A copies, B shadows/probes, C deferred/alpha, D CPU);
- an Opus second opinion that re-mined the Tracy captures per event;
- Codex and Fable reviews of the ReShade RCAO chain.

Baseline: `doc/perf_baseline_20261007.md`.

## Key correction from the per-event re-mine (Opus)
The per-frame averages hid a probe hitch on every 5th frame:
- **CPU:** probe frames take 33.2 ms against 18.7 ms for other frames. 11 ms of that is an unzoned wait at a `glClear` on framebuffer 0, issued right after swap. ReShade's present back-pressure is the likely cause.
- **GPU:** about 98% of a probe face's GPU time is one depth blit, from the small probe pack into the main 4K `mWaterDis`. It costs 5.3–6.2 ms per face.
- **What this means for the earlier reports:**
  - The "1.47 ms/frame copyContents" figure is 1.14 ms of that probe blit; the main view's copies total about 0.33 ms.
  - Main-view deferred lighting is 3.13 ms, not 4.3, and only about 0.25 ms of it is unzoned.
  - The main-view alpha/forward pass is 0.34 ms, not 1.5.

## Batch 2 candidates (medium risk, zero visual loss if done right)
- On-lens filter copy-back: draw straight into `screen` from `mReShadeSceneRaw` (−0.10 ms), which also fixes the sidecar-stomp TODO.
- ReShade G-buffer preserve: copy only when something actually clobbers the targets (−0.14 ms); needs a full audit of every writer.
- Depth-bounds/scissor for fullscreen lights whose volume contains the camera (−0.1–0.3 ms).
- Roto/Tron copy-backs: switch to ping-pong instead of copying back (about 0.18–0.25 ms each, only when those effects are on).
- Texture uploads on the GL worker thread (`RenderGLMultiThreadedTextures`): Codex measured 2.5 ms/frame in a busy scene, but uploads were small in today's capture. This needs a driver-stability A/B.

## ReShade chain (staged in `C:\Users\xianw\cxs\reshade_staging`, not deployed)
- **AO ghost fix in RTGI/RCAO.** Adds an AO-specific history clip, a minimum response for AO, and faster response on alpha/hair. It also honours the SL reset flags. Codex reviewed it: no blockers, and the one bug it found is fixed.
- **Skip Launchpad optical flow.** The viewer's motion vectors already overwrite it every frame. Opt-in defines: −0.6–0.9 ms.
- **Your call: turn MXAO off.** It is a ghost source and duplicates the RTGI AO; −0.8–1.2 ms, and it changes the look.
- **Optional quality trade-offs:**
  - TAAU scale 0.70→0.60: about −1.5 ms.
  - DIFFUSE_GI_Q 2→1: −0.5–0.8 ms.
  - DENOISER_Q 1→0: −0.6 ms.

## Quality trade-offs: user's choice only
- Spot/projector shadow slots 4→2: about −0.3 ms (they cost about 0.6 ms in total).
- Shadow cascades 0/1 at 8192→4096: about −0.7–1.2 ms. Measured per cascade: c0 1.38, c1 0.97, c2 0.30, c3 0.11 ms.
- Probe capture scale, soft-sun PCF taps, alpha shadows only in near cascades: small gains, each with a visible cost.

## Claims overturned by the second opinion
- "RenderShadowCullMode has no settings entry": it does (settings_alchemy.xml:1745). Mode 1 trades GPU for CPU.
- Caching far cascades: worth at most about 0.4 ms (c2 + c3), not 0.7–1.4.
- Alpha-mask shadow sweeps: the 31 calls/frame are mostly empty binds, about 0.05 ms or less.
- Probe face-dirtiness and capture-scale changes: the spike comes from the clear and blit above, not from capture work.
- Launchpad v4 flow: would not reduce ghosting, because the flow output is overwritten by viewer motion.

## Possible link to the ReShade depth flips
The probe-path FB 0 depth clears happen on every probe frame. ReShade's Generic Depth add-on tracks depth clears, so these clears may explain the "Generic Depth flips" note. Fix 1 may resolve it as a side effect. Untested.
