THE THINGS MOST LIKELY TO GO WRONG — get these right
=============================================================================

1. SCALE vs EXPOSURE (SA-9). Geometry scales; the inverse-square distance_ev term keeps reading the
   NOMINAL radius, never the scaled one. Feeding scaled radius into distance_ev would add up to +7.2
   stops of drift at 150x. The deferred shader normalizes distance by light size, so co-scaling the
   orbit radius and the 2.2x/1.5x falloff radii keeps subject brightness bit-identical. TUT test 3
   pins this; do not let it regress.

2. THE s = 1 FAST PATH must be a BITWISE NO-OP. mSubjectScale defaults to 1.f. The entire existing
   TUT suite must pass UNTOUCHED as the s=1 regression pin (test 1). Any reordering of the radius
   math that changes s=1 output by one ULP is a bug. Keep a literal early-out for scale == 1.f.

3. FOOT-PIVOT CENTRE (SA-4). Joint world positions do NOT include the clone's outer render scale
   (proven: llactormover.cpp:2998-3001). Map the chest joint the way gazeRenderedJointPosition does
   (foot + (point - foot) * scale), with a literal no-op when scale == 1.f. llactormover.cpp is
   READ-ONLY precedent — copy the idiom, do not call into or edit it.

4. DEGENERATE SCALE (SA-2). sanitizeGlobals must collapse s <= 0, NaN, +inf, FLT_MIN and any
   subject-lost case to 1.f BEFORE any clamp, so degenerate input renders identically to s=1
   (TUT test 8). Clamp valid scale to [0.05, 150] mirroring GHOST_SCALE_MIN/MAX by COMMENT
   (alghoststudio.h is off-limits to include; mirror the constants with a comment naming them).

5. MASTER-FILE ROBUSTNESS (B.1 fallback chain). File absent / truncated / wrong version / non-map /
   duplicate names / a "Classic 3-Point" entry inside the file must ALL degrade to "compiled Classic
   present + LL_WARNS", never a blank rig, never a crash. Compiled Classic is always master #0
   regardless of the file.

6. REFUSE ALL MASTER NAMES, not just "Classic 3-Point". saveSetup/deleteSetup and the panel Save/
   Delete gating must refuse every master name AND the combo caption/separator strings (B.5/R6),
   case-insensitively per B.4. A local must never shadow a master name.

7. RESET BUTTONS (D.1): one registered CineLightRig.ResetControl commit callback, body
   control->resetToDefault(true) on the per-button parameter setting key — mirror
   registerWeatherResetControl (alpanelweathersettings.cpp:35-51) and the weather XUI button idiom
   (panel_weather_settings.xml:46-61: image_overlay="Refresh_Off", 18x18, right-edge column). Use the
   D.1 button map for exactly which controls get one (~29). Keep the existing Reset All.

8. POSITIONAL TABLES again: the 20 file presets AND any constant tables you touch. Count and
   cross-check against the design. "It compiles" proves nothing about positional data.
