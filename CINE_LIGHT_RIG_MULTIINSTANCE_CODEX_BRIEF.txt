   VERBATIM (statement-identical, not "equivalent"): the enable/power gates, the slot resolve (for

   SELF then selects a disabled slot to peek. Correctness rests on tickFromBlob OUTPUT == tickSelected.

2. THE updateShadowPolicy INTERLOCK (§B.2a/MI-10a — a real hazard, do not skip). updateShadowPolicy
   (alcinelightrig.cpp:812-830) is the LAST step of tick and MUTATES the shared sNoShadowProjectors
   set, reading the GLOBAL CineLightRigShadowMode. Required behaviour:
   - Add `bool owns_shadows` to tick/tickSelected/tickFromBlob. The final updateShadowPolicy() call
     runs ONLY when owns_shadows (the focus rig). When false, the tick does NOT touch the shadow set.
   - Parameterize updateShadowPolicy(S32 shadow_mode) so the focus rig applies its OWN mode
     (gSavedSettings when it is also selected, else its ParamBlob.mShadowMode). No path reads another
     instance's mode.
   - applyShadowSuppression() (manager, MI-4 step 4, AFTER all ticks) force-adds all 4 projectors of
     every ENABLED NON-focus instance to sNoShadowProjectors (idempotent via isProjectorNoShadow).
   - On shutdown() the manager removes every rig UUID it added.
   For the single-rig user SELF is focus+selected => owns_shadows=true => updateShadowPolicy runs
   verbatim and applyShadowSuppression is a no-op => sNoShadowProjectors membership is byte-identical
   to today.

3. BLOB COMPLETENESS (§A.2/MI-3a — correctness, not illustrative). ParamBlob MUST capture EVERY
   settings key ANY per-instance path reads: readSettings' 40 (V11) + the tick-only 6 (V12:
   Enabled,FX,OffsetZ,Damping,TrackMode,ScaleAware) + CineLightRigShadowMode (updateShadowPolicy) +
   CineLightRigGizmo (renderGizmo) + non-settings session state (mGroupEnabled, mGroupSlots,
   mShaftEnabled[4], mHeroEnabled[4], FX phase). Enumerate ALL ~49 keys; prove each per-instance read
   is sourced from the blob (non-selected) or gSavedSettings (selected), NEVER mixed. A missed key =
   a non-selected rig silently reads the SELECTED rig's value (cross-instance leak). Runtime-derived
   state (mSmoothedCentre, mSmoothedScale, mLastFrame, emitter ptrs, retry counters) is NOT in the
   blob.

4. SLOT ANCHOR IS IMPLICIT (§A.1/MI-2). Group OFF => resolve THIS SLOT (SELF=resolve(null),
